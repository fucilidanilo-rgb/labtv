LABTV — Il mio progetto Full Stack 🎬

Una piattaforma dedicata al cinema, sviluppata con Angular, Spring Boot e MySQL.

LABTV è un'applicazione web Full Stack sviluppata come progetto portfolio per mettere in pratica le mie competenze nella programmazione frontend e backend. L'applicazione consente di esplorare un catalogo di film, effettuare ricerche, visualizzare informazioni dettagliate e gestire una libreria personale attraverso acquisti e restituzioni simulate. Il progetto integra autenticazione JWT, API REST, persistenza dei dati e distribuzione su servizi cloud.

Aiven

Il frontend Angular comunica con il backend Spring Boot tramite richieste HTTP alle API REST. Il backend gestisce autenticazione, acquisti e restituzioni, utilizzando MySQL per la persistenza dei dati. Le informazioni sui film vengono recuperate tramite l'API esterna TMDB.

Funzionalità principali

🎞️

Catalogo e ricerca film

Consultazione del catalogo cinematografico, ricerca per titolo e visualizzazione delle informazioni dettagliate dei film attraverso l'integrazione con TMDB.

🔐

Autenticazione sicura

Sistema di login basato su JWT, gestione delle autorizzazioni con Spring Security e protezione delle password tramite hashing BCrypt.

🛒

Acquisti simulati

Possibilità di aggiungere film alla propria libreria tramite operazioni gestite dal backend e registrate nel database MySQL. Non vengono effettuati pagamenti reali.

↩️

Restituzione dei film

Gestione delle restituzioni dei film precedentemente acquistati, con aggiornamento della libreria e sincronizzazione dei dati con il backend.

Sicurezza e struttura backend

Il backend è sviluppato in Java con Spring Boot e segue un'architettura organizzata in Controller, Service e Repository. Questa separazione permette di mantenere distinti gli endpoint REST, la logica applicativa e l'accesso ai dati.

L'autenticazione viene gestita tramite Spring Security e token JWT. Le password degli utenti vengono protette utilizzando BCrypt, mentre JPA e Hibernate gestiscono la persistenza nel database MySQL.

Informazioni sulla demo

LABTV è un progetto dimostrativo realizzato a scopo didattico e di portfolio. La registrazione pubblica è disabilitata e per testare le funzionalità viene utilizzato un account dimostrativo.

Gli acquisti e le restituzioni sono simulati e non prevedono transazioni economiche reali. I dati della libreria dell'account demo sono condivisi tra gli utenti che utilizzano le stesse credenziali.

⏳ Nota sul servizio di hosting gratuito

Il backend di LABTV è ospitato su Render Free, un servizio gratuito che può sospendere temporaneamente l'applicazione dopo un periodo di inattività. Per questo motivo, il primo accesso o la prima richiesta API potrebbero richiedere un minuto o più, mentre il server viene riattivato. Le richieste successive sono generalmente più veloci.
