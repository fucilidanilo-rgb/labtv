# LABTV

LABTV è un’applicazione web sviluppata con Angular per la consultazione e la gestione di film.

## Funzionalità

- Registrazione e accesso degli utenti
- Visualizzazione del catalogo dei film
- Ricerca dei film
- Visualizzazione dei dettagli
- Acquisto dei film
- Gestione dei film acquistati
- Navigazione tramite Angular Router
- Simulazione del backend con JSON Server

## Tecnologie utilizzate

- Angular
- TypeScript
- HTML
- CSS
- JSON Server
- Git e GitHub
